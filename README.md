# WTranslator

**WTranslator** 是一款专为 **Microsoft Word 深度阅读**（并支持扩展至全局窗口）打造的轻量级英汉划词翻译与语境生词复习工具。

---

## 核心功能

### 1. 无感划词与隐形搜句
* **半透明 `T` 字悬浮图标**：在 Word 中双击或拖拽划选英文后，鼠标旁自动浮现无焦点半透明 `T` 图标（不抢夺焦点、不破坏文档蓝色选区），点击即弹出解析卡片。
* **100% 隐形搜索句首和句尾**：基于 Word COM 内存克隆技术 (`Selection.Range.Duplicate`) 与缩写感知算法（自动过滤 `Mr.`、`e.g.`、`U.S.` 等缩写句点），在后台隐形提取当前词所在的完整句子，界面选区零闪烁。
* **句子词数上限保护**：当所在句子超过设定词数上限（默认 `50` 词，可在设置中调整）时，自动拦截长句发送并在弹窗内提示超限，仅查询词条本身以节省 Token 与响应时间。

### 2. 智能词数分流与增量更新
* **单词模式（1 词）**：像词典一样返回**音标**、**多个词性及对应释义**、**在当前句子中的具体用法**与**整句翻译**，并结构化存入本地数据库供复习调用。
* **短语模式（2 ~ 5 词）**：由 AI 自动鉴别是否构成固定短语/习惯搭配：
  * **构成短语**：返回音标、短语意思（无需词性）与句中用法，并结构化入库供复习；
  * **非固定短语**：直接返回片段译文，不入库。
* **句段模式（$\ge 6$ 词或多句段落）**：直接进行流畅翻译，不入库。
* **重复划词增量更新**：再次划到已收录的单词或短语时，直接复用本地音标与基础词义，**仅向 AI 发送新句子**以获取句译和该句中的用法，追加至该词的历史例句库。

### 3. 三色英语复习卡片系统（现代灰感暗色调）
* **灰调蓝框（正常卡片）**：新收录或近期已复习的词语与短语。
* **灰调红框（超期提醒）**：距离上次复习（或首次收录）**超过一周（7 天）**未复习的词条自动标红提醒。
* **灰调黄框（「又回来啦」）**：支持软删除卡片（从复习列表移除但保留底层数据）；若日后阅读时再次划到该词，卡片会自动以黄色边框重新回归并显示「又回来啦」。
* **一键打卡与例句展开**：
  * 点击卡片任意空白处即代表**已复习一次**（自动累加复习次数、记录距上次复习的时间间隔，并将红框/黄框恢复为蓝框）；
  * 点击「展开句子」可查看所有遇到过该词的英文原句（目标词高亮）、译文及句中用法解析。

### 4. 在线模型拉取、自定义存储与 GitHub 热更新
* **在线拉取模型名称**：在 `⚙ 设置` 中填写 API Key 与 Base URL 后，点击「拉取模型列表」即可从服务端实时获取可用模型并下拉选择。
* **可靠存储与目录自选**：基于 SQLite WAL 高可靠模式，默认存储在程序安装目录，支持在设置中自由更改存储目录并自动无损迁移数据。
* **GitHub 在线更新 (OTA)**：点击界面右上角「在线更新」即可直接从 GitHub 同步最新代码修复或升级版本，本地词库与配置永久保留。

## 快速使用

1. **直接运行**：
   * 双击桌面上的 **WTranslator** 快捷方式，或双击项目目录下的 `run.bat`。
2. **首次设置**：
   * 点击主界面右上角 **`⚙ 设置`**，选择服务商预设（DeepSeek / 硅基流动 / 通义千问 / 智谱 / OpenAI）或填入自定义接口，点击「拉取模型列表」选择模型并保存。
3. **打包独立目录版**：
   * 双击运行 `build_exe.bat`，即可在 `dist\WTranslator\` 下生成极速启动的独立桌面程序并自动创建带专属图标的桌面快捷方式。
